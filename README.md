# probeclip

Probe identifiers and clip tokens for idempotent workflows.

**Site:** https://theworker02.github.io/probeclip/

## Install / run

```bash
git clone https://github.com/theworker02/probeclip.git
cd probeclip
node src/cli.js
node --test
```
